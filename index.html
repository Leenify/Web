Adicción a las Redes Sociales

El uso excesivo de las redes sociales puede convertirse en un hábito difícil de controlar.

¿Qué es?

La adicción a las redes sociales ocurre cuando una persona siente una necesidad constante de revisar sus redes, publicar contenido o permanecer conectada durante largos periodos.

Principales consecuencias

  • Pérdida de concentración.
  • Problemas para dormir.
  • Menor convivencia con familiares y amigos.
  • Distracción durante las actividades escolares.
  • Dificultad para dejar de utilizar el celular.

¿Cómo prevenirla?

Una buena forma de prevenir el uso excesivo es establecer horarios para utilizar las redes sociales y dedicar tiempo a otras actividades.

También es recomendable evitar utilizar el celular durante las comidas y antes de dormir.

Recuerda

Las redes sociales son una herramienta, pero no deben controlar nuestro tiempo.
